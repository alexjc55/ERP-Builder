# Шаблоны оформления карточек

В конструкторе карточки откройте панель «Стиль» → «Шаблоны оформления».
Настройте оформление, введите название и нажмите «Сохранить как новый».
Шаблон хранится в базе и доступен во всех сущностях пользователям с правом
управления конструктором карточек.

Для другой формы выберите шаблон и нажмите «Применить оформление».
Переносятся стиль, тип окна/панели, цвета, отступы, скругление, размер
шрифта, рамки и тени разделов. Вкладки, разделы, поля, тексты и привязки
не заменяются. Затем сохраните карточку обычной кнопкой:
черновик останется черновиком, опубликованная форма обновится при сохранении.

«Обновить выбранный» сохраняет текущее оформление и название в выбранном
шаблоне; «Удалить шаблон» удаляет его из общего списка.
Обе операции требуют подтверждения. Уже оформленные карточки не меняются.
При параллельном изменении сервер возвращает конфликт, а не затирает правки:
повторно выберите шаблон из обновлённого списка.

## Удалённый сервер

Перед использованием выполните `scripts/migrate-card-style-presets.sql`,
затем обновите API и интерфейс. Скрипт создаёт только новую таблицу.
Данные карточек и опубликованные формы не изменяются.
